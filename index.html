Phase 1: Foundational Efficiency & Navigation

Keyboard Navigation Protocols

Traverse search results without touching the mouse.

  • • J / K: Move down and up through result links
  • • D: Domain search on highlighted item
  • • /: Instant cursor focus to search box
  • • M: Return to main search results tab
  • • T: Jump straight to top of page
On-the-Fly Utility Commands

Execute instant computational and security utilities.

  • • password [number]: Generate secure passphrase
  • • timer [time]: Start interactive countdown
  • • shorten [url]: Compress target link
  • • html chars: HTML entity quick reference
  • • ascii: ASCII code table lookup

Phase 2: Core Research & Information Retrieval

Targeted Filtering & Placement

Filter formats and isolate precise word positioning.

  • • site: restrict results to specific domain
  • • filetype: filter extensions (pdf, doc, csv)
  • • intitle: force keyword in document title
  • • inurl: force keyword in URL path
  • • inbody: force keyword in page body text
Advanced Boolean Logic

Dual purpose: complex queries & syntax troubleshooting.

  • • AND: Require both terms (must be uppercase)
  • • OR: Match either term
  • • -term: Exclude unwanted results
  • • "exact phrase": Lock exact word ordering
